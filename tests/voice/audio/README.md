# Test inputs, not test recordings

Each file here is **one customer phrase**, synthesised with Deepgram Aura (`aura-2-apollo-en`).
The test runner (`../run.mjs`) streams these phrases into the app as microphone audio, one turn at a time.

**Recordings of the full test conversations** (customer + agent, T1–T9) are in
[docs/evidence/voice-tests-2026-09-28/](../../../docs/evidence/voice-tests-2026-09-28/), with transcripts and results in its `summary.md`.
